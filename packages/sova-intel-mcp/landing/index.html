Setup

Running in under two minutes.

No SDK. No wrapper. Just config and a restart.

1
Get an API key at sova-intel.com
2
Add to your MCP client config
claude mcp add sova-intel \
  -e SOVA_API_KEY=ak_your_key \
  -- npx -y "@sova-intel/mcp"
{
  "mcpServers": {
    "sova-intel": {
      "command": "npx",
      "args": ["-y", "@sova-intel/mcp"],
      "env": { "SOVA_API_KEY": "ak_your_key" }
    }
  }
}

Claude Desktop: %APPDATA%\Claude\claude_desktop_config.json (Windows)  /  ~/Library/Application Support/Claude/claude_desktop_config.json (Mac)
Cursor: .cursor/mcp.json in your project root

3
Restart your client and confirm sova-intel appears connected.
4
Ask your first question.
Try any of the three prompts above. The MCP handles everything from there.
