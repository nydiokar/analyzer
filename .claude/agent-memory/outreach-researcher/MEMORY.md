## Key Patterns Observed

### What Builders Care About
1. **Agent frameworks** - ElizaOS, Solana Agent Kit, Vercel AI SDK compatibility
2. **Speed & latency** - Sniper bots, copy trading bots want sub-10ms execution
3. **Social + onchain integration** - Twitter agents, sentiment-driven traders
4. **Protocol coverage** - Raydium, Jupiter, Pump.fun, Magic Eden integrations
5. **Real shipped products** — Winners of hackathons or live tokens have credibility
